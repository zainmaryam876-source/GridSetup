## 🚀 Getting started with the dashboard

Double-click the GridSetup icon on your desktop to open the program. The dashboard displays a series of cards. Each card represents a specific tool.

### Radio and SDR
Connect your radio receiver via USB. Select the SDR card in the dashboard. The software detects your device and shows a visual representation of radio waves. Use the sliders to change frequency ranges.

### Satellite tracking
Select the satellite tool to view real-time locations of objects in orbit. The map shows flight paths and orbital data. The dashboard updates this information automatically when you connect to the internet.

### Network tools
The network section shows devices currently connected to your local internet. It lists IP addresses and device types. You can use these features to monitor your home network traffic.

### Microcontroller and IoT
If you use ESP32 or Arduino boards, connect them to your computer. The dashboard recognizes these boards. You can monitor sensor data or toggle switches on your devices through the interface.

### Computer vision
Access the camera tool to view live video feeds. The software identifies objects within the frame. You can set alerts to notify you when the camera detects movement.

## ❓ Frequently asked questions

**Does this software require programming?**
No. You control every feature through the visual dashboard.

**How do I remove the software?**
Open your Windows Settings, go to Apps, find GridSetup in the list, and select Uninstall.

**Can I run this on a tablet?**
The software is designed for Windows desktop and laptop computers. It does not support mobile operating systems like Android or iOS.

**What do I do if a device does not appear?**
Check your USB cable. Make sure you connect your hardware directly to your computer. Some devices require a restart of the dashboard to appear in the list.

**Does this software track my private data?**
No. All data processing occurs on your local machine. The dashboard does not send your personal information or network data to external servers.
